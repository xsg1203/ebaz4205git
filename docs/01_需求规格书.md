# 需求规格书 · ZYNQ-7010 多运动目标颜色识别与追踪系统

| 项 | 内容 |
|---|---|
| 文档编号 | SPEC-CT-001 |
| 版本 | v1.0 |
| 项目代号 | CT-EBAZ4205（Color Tracking on EBAZ4205） |
| 目标器件 | xc7z010clg400-1（Zynq-7010，速度等级 -1，工业级） |
| 开发环境 | Vivado 2017.4 / Verilog-2001（RTL 全同步设计） |
| 实现方式 | **纯 PL 逻辑**（不使用 PS / DDR3 / VDMA / 软核） |

---

## 1. 功能需求（F）

| 编号 | 需求 | 实现要点 |
|---|---|---|
| F1 | OV5640 实时采集 | DVP 8bit，RGB565，640×480@30fps；PCLK 域采集 + 异步 FIFO 跨域 |
| F2 | SCCB 配置摄像头 | I2C 主机 + 寄存器配置 ROM；开启 AWB/AEC |
| F3 | 运动目标检测 | 4×4 像素块降采样为 160×120 网格，块内亮度求和；帧差 + 阈值 → 块级运动掩膜 |
| F4 | 颜色分类 | 每 4×4 块内做 5 类颜色投票（16 像素中胜出类别 ≥6 票），输出块颜色类别（3bit） |
| F5 | 多目标分离 | 块级单遍 4 邻域连通域标记（并查集），分离同色多目标 |
| F6 | 目标筛选 | 面积门限（≥12 块）滤噪；每帧最多 16 个目标 |
| F7 | 框选显示 | 每目标 2px 边框，**边框颜色 = 目标颜色**，VGA 叠加层生成 |
| F8 | 目标 ID | 帧间质心最近邻匹配（距离门限 24 块），匹配继承 ID，否则新建 |
| F9 | 单色持续追踪 | 选定颜色中面积最大者为追踪对象；丢失保持 ≤15 帧（0.5s），按速度外推 |
| F10 | 按键控制 | key1/key2：追踪颜色 +/-（五色循环）；key3：单色追踪开关；key4：五色全框选开关 |
| F11 | VGA 输出 | 640×480@60Hz RGB565，像素时钟 25MHz；320×240 帧缓存 2×2 放大显示 |
| F12 | OSD 信息 | 五色图例、选中颜色高亮、模式文字、目标 ID、帧率 |

### 按键与显示状态机

| 当前状态 | key4 按下 | key3 按下 | key1 / key2 |
|---|---|---|---|
| OFF（原图直显） | → ALL | → SINGLE | 切换选中颜色 |
| ALL（五色全框选） | → OFF | → SINGLE | 切换选中颜色（仅高亮图例） |
| SINGLE（单色追踪） | → ALL | → OFF | 切换追踪颜色，框立即切换 |

### 按键引脚（低有效，10K 上拉）

| 按键 | Zynq 引脚 | 功能 |
|---|---|---|
| KEY_1 | G19 | 追踪颜色 -1 |
| KEY_2 | J19 | 追踪颜色 +1 |
| KEY_3 | K19 | 单色追踪 开/关 |
| KEY_4 | L16 | 五色全框选 开/关 |

### LED 指示（低电平点亮，one-cold）

- LED0（H20）：ALL 模式亮
- LED1（K18）：SINGLE 模式亮
- LED2（J20）/ LED3（L19）：选中颜色索引（二进制）

## 2. 性能需求（P）

| 编号 | 指标 | 目标值 |
|---|---|---|
| P1 | 处理帧率 | ≥ 30 fps |
| P2 | 端到端延迟 | ≤ 2 帧（≈67ms），远小于 0.5s |
| P3 | 颜色分类准确率 | ≥ 90%（标准室内光照） |
| P4 | 追踪稳定性 | 连续 10s 不丢框、不漂移 |
| P5 | 多目标容量 | 同帧 ≥10 目标、≥5 色、每色 ≥2 |
| P6 | 光照鲁棒性 | 300~800 lux 内准确率下降 ≤10 个百分点 |
| P7 | 资源占用 | LUT < 80%；BRAM ≤ 80%；WNS ≥ 0 |

## 3. 平台与接口（H）

| 项 | 规格 | 引脚/说明 |
|---|---|---|
| 主时钟 | 50MHz（X5） | N18，`create_clock -period 20.000` |
| 派生时钟 | 100MHz（系统）、25MHz（VGA/OV_XCLK） | MMCM |
| 摄像头时钟 | OV_XCLK 24MHz 由 PL 输出 | F20 |
| PCLK | 摄像头提供，非专用时钟脚 | E19，XDC 需 `CLOCK_DEDICATED_ROUTE FALSE` |
| 按键 | 低有效 | G19/J19/K19/L16 |
| LED | 低电平点亮 | H20/K18/J20/L19 |
| VGA | RGB565 + HSYNC/VSYNC | 电阻网络 DAC |
| 复位 | 板上无复位键 | 上电复位（POR 计数器 1ms） |

## 4. 关键设计决策（D）

| 编号 | 决策 | 结论 |
|---|---|---|
| D1 | 显示通道 | 320×240 RGB565 单帧缓存，VGA 端 2×2 放大（BRAM 34/60） |
| D2 | 多目标分离 | 块级单遍 CCL（4×4 块，160×120 网格） |
| D3 | 颜色分类 | 通道比较 + 块内投票（不引入 HSV/除法器） |
| D4 | 运动检测粒度 | 4×4 块级（与颜色分类共用块流水线） |
| D5 | 时钟域 | PCLK / clk_sys(100M) / clk_pix(25M) / clk50(50M) |

## 6. 风险清单

| 编号 | 风险 | 等级 | 缓解 |
|---|---|---|---|
| R1 | BRAM 73% 偏紧 | 中 | 字库压缩 → 目标表减 12 → 降 RGB332 |
| R2 | LUT 预估偏差 | 中 | CCL 复用 ALU；块网格退化为 8×8 |
| R3 | PCLK 走非专用时钟脚 | 高 | XDC 加 `CLOCK_DEDICATED_ROUTE FALSE` |
| R4 | 单缓冲帧撕裂 | 低 | 接受 |
| R5 | 同色目标物理粘连 | 中 | 块级形态学腐蚀 + CCL |
| R6 | 无复位按键 | 低 | POR + 组合键软复位 |
| R7 | 光照突变阈值失效 | 中 | AWB/AEC + 阈值在线可调 |
| R9 | 紫色与蓝色 RGB 距离近 | 中 | 紫色判据要求 R、B 同时高于 G |

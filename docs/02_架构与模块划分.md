## 1. 三级层次划分

```
系统层  ct_top                     —— 时钟/复位、域连接、外设绑定
子系统层
  ├─ video_in    采集子系统         ov5640_capture + 帧缓存写侧
  ├─ vision      视觉算法子系统     block_stat / motion / ccl / comp_stat / tracker
  ├─ video_out   显示子系统         帧缓存读侧 + vga_timing + overlay + osd
  └─ ctrl        人机子系统         key_debounce + mode_fsm
模块层  各 .v 单文件
```

**分层原则**：子系统之间只通过「帧同步脉冲 + 目标表 + 像素流」三类信号交互，禁止跨层直连内部寄存器。

---

## 2. 时钟与复位

| 时钟 | 来源 | 频率 | 承载 |
|---|---|---|---|
| clk50 | N18 晶振 | 50MHz | POR、SCCB 配置 |
| clk_sys | MMCM CLKOUT0 | 100MHz | 块帧差、CCL、统计、追踪、按键 |
| clk_pix | MMCM CLKOUT1 | 25MHz | VGA 时序、帧缓存读、叠加 |
| ov_pclk | OV5640 E19 | 24~48MHz | DVP 采集、块累加 |

MMCM 配置：`DIVCLK=1, MULT=18.000 → VCO 900MHz`；`CLKOUT0_DIVIDE_F=9.000 → 100MHz`；`CLKOUT1_DIVIDE=36 → 25MHz`。25MHz 同时作为 OV_XCLK（640×480@25MHz 刷新 59.5Hz）。

**复位**：板上无复位键 → `por_reset` 产生 1.3ms 上电复位；每个非 clk50 域经 `rst_sync` 做异步复位、同步释放。

## 3. 模块接口表

### 3.1 video_in 子系统

| 模块 | 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|---|
| ov5640_capture | ov_pclk | in | 1 | 像素时钟 |
| | ov_vsync / ov_href | in | 1 | 帧/行有效 |
| | ov_data | in | 8 | DVP 数据 |
| | pix | out | 16 | RGB565 |
| | pix_vld | out | 1 | 像素有效 |
| | cx / cy | out | 10/10 | 像素坐标 |
| | frame_start | out | 1 | VSYNC 上升沿单拍 |

### 3.2 video_out 子系统

| 模块 | 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|---|
| frame_buf | wr_clk/wr_addr/wr_data/wr_en | in | 1/17/16/1 | 写侧（pclk 域，2×2 降采样） |
| | rd_clk/rd_addr/rd_data | in/out | 1/17/16 | 读侧（clk_pix 域） |
| vga_timing | x / y | out | 10/10 | 当前像素坐标 |
| | de / hsync / vsync | out | 1 | 显示有效与同步 |

### 3.3 目标表（跨子系统唯一数据契约，M4 起生效）

| 字段 | 位宽 | 说明 |
|---|---|---|
| valid | 1 | 本帧有效 |
| color | 3 | 0=背景 1=红 2=绿 3=蓝 4=黄 5=紫 |
| id | 5 | 跨帧稳定编号 1~31 |
| x0,y0,x1,y1 | 4×10 | 外接框（块坐标，显示 ×4） |
| area | 12 | 块数 |
| tracked | 1 | 是否为当前追踪目标 |

目标表 16 项 × 60bit，双缓冲，写在 clk_sys 域，读在 clk_pix 域。

## 4. CDC 清单

| 编号 | 跨域信号 | 源→目的 | 手段 |
|---|---|---|---|
| C1 | pix/pix_vld/cx/cy | ov_pclk → clk_pix | 双口 BRAM 独立时钟 |
| C2 | 块流 | ov_pclk → clk_sys | 异步 FIFO |
| C3 | 帧结束标志 | clk_sys → clk_pix | 电平翻转 + 2FF |
| C4 | 目标表 bank 切换 | clk_sys → clk_pix | bank 指针 2FF + 双缓冲 |
| C5 | 按键 | clk50 → clk_sys | 2FF + 20ms 消抖 |
| C6 | MMCM locked | — → 各域 | 复位释放条件 |

**硬规则**：跨域只允许 1bit 电平/脉冲或经 FIFO 的多 bit 总线。

## 5. 资源分配预算

| 子系统 | BRAM36 | LUT |
|---|---|---|
| video_in | 0 | ~0.6K |
| video_out | 34（帧缓存）+1（字模） | ~2.0K |
| vision | ~7 | ~6.0K |
| ctrl | 0 | ~0.5K |
| 时钟/复位 | 0 | ~0.2K |
| **合计** | **~43 / 60（72%）** | **~9.3K / 17.6K（53%）** |
